### About me

I lead engineering teams that ship and scale enterprise software, and I still write code every week. My work sits where **platform architecture**, **team leadership** and **applied AI** meet.

- 🧭 **Leadership.** I build and mentor teams, run delivery end to end, and turn ambiguous business problems into systems that hold up in production.
- 🏗️ **Architecture.** Microservices, performance engineering and web-scale system design across the JavaScript/TypeScript, Python and AWS stack.
- 🤖 **Agentic AI.** I'm building tooling to make LLM agents reliable, from MCP server evaluation to tool-selection benchmarking.
- ✍️ **Writing.** I write about system design, scaling and web engineering on [Medium](https://medium.com/@danivijay).
